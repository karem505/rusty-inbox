Bug fixes for 0.2.0: Rusty Inbox now starts on KDE Plasma, follows the desktop's dark mode outside Omarchy, and the composer and the daily briefing are readable on dark themes.

### Fixes
- **KDE Plasma: the app no longer crashes at start** (#4). It aborted with "Cannot create a QWidget without QApplication": Plasma's platform theme builds the tray menu and the file dialogs as Qt widgets, and the app object did not support widgets. It does now, so the tray menu and the native KDE file dialogs work as well.
- **Theme "System" follows the desktop's light/dark mode** (#5). Outside Omarchy the app always opened light. It now reads the desktop's preference through the XDG desktop portal (GNOME, KDE Plasma, COSMIC and every Flatpak) and switches live when you change it. On Omarchy nothing changes: the Omarchy theme still decides.
- **Quoted text in replies is readable on dark themes** (#6). Inside the composer the quote now follows the app's colours; the message you send keeps the original formatting.
- **Links in the daily briefing use the theme's accent colour** (#7), the same for the release notes and update instructions in Settings → Updates. They were Qt's default blue, which is hard to read on dark themes.
- **Replace keeps the space before the quote and the signature** (#8). Accepting a Proofread, Rewrite, Translate or Write for me result used to remove the blank line between your text and the "On …, X wrote:" line, and could pull the signature up against it.

Thanks to @mujeebcpy and @AuthenticSm1les for the reports, and to @AuthenticSm1les for packaging Rusty Inbox on the AUR (`yay -S rusty-inbox`).

### Install
- **Flatpak (recommended on Linux):** `flatpak install --user https://karem505.github.io/rusty-inbox/rusty-inbox.flatpakref`. Already installed: `flatpak update`.
- **Arch Linux:** `yay -S rusty-inbox` (AUR, community package).
- **Linux:** AppImage, `.flatpak` bundle or tarball below, or `curl -fsSL https://raw.githubusercontent.com/karem505/rusty-inbox/main/scripts/install.sh | sh`.
- **Windows:** `setup.exe` or the portable zip.
- **macOS:** `.dmg` for Apple Silicon (arm64) or Intel (x86_64).
- **Already on 0.1.2 or later:** Settings → Updates.

Checksums are in `SHA256SUMS`.
