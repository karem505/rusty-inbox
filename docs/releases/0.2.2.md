Rusty Inbox now runs on 64-bit ARM Linux too: an AppImage, a tarball and the Flatpak for aarch64, next to the x86_64 builds.

### New: Linux on ARM64 (aarch64)
- **Flatpak:** the same command installs the right build for your processor, on x86_64 and aarch64: `flatpak install --user https://karem505.github.io/rusty-inbox/rusty-inbox.flatpakref`. A standalone `rusty-inbox-0.2.2-aarch64.flatpak` bundle is attached too.
- **AppImage and tarball:** `rusty-inbox-0.2.2-aarch64.AppImage` and `rusty-inbox-0.2.2-linux-aarch64.tar.gz`. The AppImage needs glibc 2.39 or newer (Ubuntu 24.04, Debian 13, Fedora 40 and later), because Qt's ARM64 builds target Ubuntu 24.04. On older systems use the Flatpak.
- **In-app updates and the install script** now pick the ARM64 files on ARM64 Linux, so these installs update themselves from Settings → Updates like the x86_64 ones.
- Windows on ARM keeps using the x64 build, which runs through Windows' emulation: Qt 6.8 has no WebEngine for Windows ARM64, and Rusty Inbox needs it to show and write mail.

### Builds
- The release and Flatpak pipelines moved to the current GitHub Actions versions, and the Flatpak repository is now published only from a release.

No changes to the app itself on x86_64, Windows or macOS: 0.2.2 is the same app as 0.2.1 there.

### Install
- **Flatpak (recommended on Linux, x86_64 and aarch64):** `flatpak install --user https://karem505.github.io/rusty-inbox/rusty-inbox.flatpakref`. Already installed: `flatpak update`.
- **Arch Linux:** `yay -S rusty-inbox` (AUR, community package).
- **Linux:** AppImage, `.flatpak` bundle or tarball below for x86_64 or aarch64, or `curl -fsSL https://raw.githubusercontent.com/karem505/rusty-inbox/main/scripts/install.sh | sh`.
- **Windows:** `setup.exe` or the portable zip (x64; also runs on Windows on ARM).
- **macOS:** `.dmg` for Apple Silicon (arm64) or Intel (x86_64).
- **Already on 0.1.2 or later:** Settings → Updates.

Checksums are in `SHA256SUMS`.
