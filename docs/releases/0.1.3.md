New mail the moment it arrives, attachments you can download, and a card for every person in a message.

### New mail arrives at once
- **Push (IMAP IDLE).** Each account keeps one connection waiting on its Inbox. When the server announces new mail, the Inbox is synced right away: new mail shows in about a second instead of after the next check (every minute, after every folder of every account). Servers without IDLE are still checked on the interval set in Settings.
- If the connection drops (network change, sleep, server restart), it reconnects by itself and catches up on what arrived in between.
- During a regular check, each account's mail shows as soon as that account is done, without waiting for the slowest one.

### Fix: replies to Done or snoozed conversations were hidden
A new message in a conversation you had marked **Done** (or snoozed) was stored, but the conversation stayed Done, so the newest mail never showed in the Inbox while other mail apps showed it. New mail arriving in the Inbox now brings the conversation back, like other mail apps do.

### New: download attachments
- **Click an attachment to open it** in the app your system uses for that kind of file. It is downloaded from the server the first time and kept in the local cache after that.
- **Save** (the arrow next to each attachment) asks where to put the file, starting in your Downloads folder. **Save all** puts every attachment of a message in a folder you pick. Existing files are never replaced: a second copy is saved as `name (1).pdf`.
- Files that can run programs (`.exe`, `.bat`, `.sh`, `.desktop`, …) are not opened directly; their folder opens instead, so you decide.
- File names from mail are cleaned before they touch your disk (no folders, no characters Windows rejects).

### New: people in a message
- **Every name and address in a message is clickable**: the sender and everyone in **To**, **Cc** and **Bcc** (Bcc shows on mail you sent).
- It opens the person's **card**: their name and address, how many messages you have from and to them, and your latest conversations with them.
- From the card: **Write email** (sent from the account the conversation belongs to), **Copy address**, **All conversations** (a list of every conversation with them), or open one of the recent conversations.

### Other fixes
- **Attachments of large messages show up.** Messages above the full-download limit are synced header-only; their attachments are now recorded when you open the message (messages opened before this version are repaired the next time you open them).

### Install
- **Flatpak (self-hosted, signed):** `flatpak install --user https://karem505.github.io/rusty-inbox/rusty-inbox.flatpakref`. If you already have it, run `flatpak update`. The Flatpak can now write to your Downloads folder by default; other folders go through the system file chooser.
- **Linux:** AppImage, `.flatpak` bundle or tarball below, or `curl -fsSL https://raw.githubusercontent.com/karem505/rusty-inbox/main/scripts/install.sh | sh`. If you're already installed, add `-s -- --update`.
- **Windows:** `setup.exe` or the portable zip.
- **macOS:** `.dmg` for Apple Silicon (arm64) or Intel (x86_64).
- **Already on 0.1.2:** *Settings → Updates → Check now* installs it.

Checksums are in `SHA256SUMS`.
